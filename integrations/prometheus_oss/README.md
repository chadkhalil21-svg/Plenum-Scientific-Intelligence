# Prometheus open-source orchestration adoption

Upstream libraries (MIT): [Deep Agents](https://github.com/langchain-ai/deepagents), [LangGraph](https://github.com/langchain-ai/langgraph), [SQLite checkpointer](https://github.com/langchain-ai/langgraph/tree/main/libs/checkpoint-sqlite). Pinned published direct versions; transitive dependency freeze retained by CI, not a reviewed full lock yet.

Paperclip remains the existing workforce manager. This candidate calls the real Deep Agents harness and upstream LangGraph SQLite persistence rather than writing another agent loop. It accepts independently validated synthesis work products via the existing synthesis contract, exposes only reviewed read/estimate/decision tools and the virtual todo planner, and routes all inference through the existing original-digest Qwen3.5:4b loopback adapter. No hosted LangSmith, provider credentials, unrestricted shell, host filesystem, external spending, arbitrary network tools or private grants. Model requests are immutably reserved; ambiguous reservations fail closed. The graph's synthetic qualification intentionally stops after an acknowledged read tool and resumes on the same SQLite thread in a separate Python process. A distinct held-out budget case tests the opposite decision. Verification reopens the graph without inference, compares independent expected arithmetic and actual model/tool receipts. The workflow stops Qwen before verification.

This is a staged integration alongside PR #912, not replacement of accepted production code. Native Paperclip calls, all 5 divisions and 11 work products, general subagent delegation, dynamic multi-mission graphs, live owner-private board continuity and private database disaster recovery still require integration and live qualification. The synthetic graph archive is not private production proof. No permanent server is required or provisioned. Self-hosted open source has no licence charge; account-level infrastructure billing remains a separate check. Never publish private SQLite state in GitHub Actions.
