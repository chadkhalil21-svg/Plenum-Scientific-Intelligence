# Research Director public video rulebook
Public captions are a different evidence class from YouTube title/tags, description, chapters, creator links or a third-party summary. The existing no-key original project worker `plenum_ai.youtube_public_caption_worker` attempts captions once per founder-approved video ID and stores only reviewed product names/times, not a verbatim copyrighted transcript. If a cloud IP blocks access, mark CAPTION_UNAVAILABLE, preserve the original creator description, and do not claim full viewing. Do not spend a metered transcript credit without approval.
List every substantiated named platform by video. Label featured tools, incidental tools, author self-promotion, and conjectural use cases separately. Verify pricing and licenses against original vendor pages. If a free tier sleeps or has credits, do not advertise it as a permanently running free private AI host. Accepted output requires links and honest capability/status labels, not 100 unrelated generic URLs.
