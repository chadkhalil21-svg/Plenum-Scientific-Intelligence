# Authenticated browser and external tools
Prefer a properly connected provider app or documented API for approved Gmail, Google Drive, GitHub or other account work; use the Plenum Browser or an approved Playwright session only when no suitable API exists. Never assume a saved sign-in works on all websites. The account holder authorizes access through the legitimate service; public research permissions do not grant private actions or payment rights. The browser issue #310 retains the missing owner-approved multi-step task and independent readback. A Cloudflare Free wake endpoint is not an authenticated headless browser or persistent Hermes host.
