# Plenum | Small tool-specific agent rulebooks
Keep instructions narrow. Route through existing connected apps when actually present, not browser logins for every tool. Private account permission is never inferred from a public repo file.
- `github.md`: source code, six-video public research and evidence acceptance
- `gmail.md`: humanized business draft and reply, actual send only when explicitly requested
- `google-drive.md`: verified institutional source documents, permission boundaries
- `public-video-research.md`: real captions/creator descriptions vs generic metadata
- `browser.md`: API/connector-first, owner-authenticated browser for unserved workflows
Read only the one relevant rulebook for a task, not all five. The founder's private Document Production Standards Ledger stays private in connected Google Drive.
