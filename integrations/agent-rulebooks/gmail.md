# Gmail writing and action rulebook
Use the actually connected Gmail tool only when available; read the exact intended thread and recipient. Apply original source-preserving institutional or principal-to-principal tone, then a brief Humanizer pass. No invented names, dates, legal claims, sponsor figures or contact addresses. Never treat drafting as sending; actual sending or recipient changes require the user-directed instruction and a host-confirmed action result. Do not copy private mail to a PUBLIC GitHub agent. Avoid duplicate signature or lengthy ceremonial close; ask one factual question only when essential.
