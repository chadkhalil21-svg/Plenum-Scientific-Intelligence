# Plenum | Free Hosting for Named AI Workers
**Decision basis:** Official provider pricing and runtime limitations checked 2026-11-10. Free tier ≠ unlimited costs, uptime or model intelligence. **No new cloud host or billing setting was created by this comparison.**

| Provider | Current genuinely free opportunity | Can run Hermes continuously? | Caution |
|---|---|---|---|
| **Oracle Cloud Always Free A1** | Current Always Free documentation describes approximately **2 Arm OCPUs and 12 GB RAM** for a full month, with home-region networking and storage quotas. | **Best free candidate:** potentially a private Hermes gateway and a small CPU Qwen/Ollama model after benchmarks. | Requires new eligible Oracle account (typically card + phone), A1 stock can be exhausted, underused VMs can be reclaimed. Never accept PAYG overage by mistake. |
| **Google Compute Engine e2-micro** | One eligible e2-micro VM/month, ~1 GB RAM, 30 GB standard disk in us-central1/us-east1/us-west1. | **Possibly for gateway only**, not capable autonomous local model worker; model would need an independently free permitted provider. | Separate **external IPv4 currently charges ~$0.005/hour** (save by no external IPv4, but outbound Telegram access then needs a no-cost verified networking path). Extra egress/other services may bill. Not guaranteed $0 with public IP. |
| **Google Cloud Run (request-based)** | Up to **2 million requests**, 180k vCPU-seconds and 360k GB-seconds/month in the eligible free tier; scale to zero with min-instances=0. | **Good for Telegram/Meta HTTPS webhook ingestion and short work triggered by messages, NOT a continuously connected polling Hermes gateway.** | Google documents background CPU is severely limited after HTTP response; min-instances>0 costs; builds, registry, egress, excess consumption can cost. Existing browser Cloud Run service must remain isolated. |
| **Cloudflare Workers Free + D1** | 100k HTTP requests/day, limited CPU/DB quota; free durable SQLite-backed D1. | **Good for a tiny webhook + state/dispatch frontend**, not the full Python Hermes gateway or local LLM model. | Free 10ms CPU/event, running other compute/model is a separate dependency. Requires a separate account/setup; do not duplicate existing GitHub task inbox without cause. |
| **GitHub Actions public repo** | Already used by Plenum for read-only/limited public tasks; events and schedules. | **No.** Short-lived, potentially delayed runners only. | Never run private Telegram messages, customer data, phone numbers or real business credentials in public repository builds. Can post only nonconfidential task status through opt-in secret. |
| **Render Free** | 750 free instance-hours per workspace/month (other quotas apply). | **No reliable persistent gateway:** sleeps after 15 min inactivity and filesystem resets; free Postgres expires after 30 days. | Any already-paying Render service does not make new instances free. Avoid. |
| **Vercel Hobby / functions** | Free request-driven limited functions. | **No** always-on process; WebSocket server unsupported. | Useful short webhooks, not Hermes server. |
| **Hostinger / typical VPS** | Paid hosted virtual servers; promotions do not establish indefinite no-charge operations. | Yes when paid. | Excluded from strict $0. |
| **Cloud Shell, ephemeral Codespaces, Hugging Face Spaces, free notebooks** | Interactive or limited free allowances. | **No reliable 24/7 promise** for a production private bot. | Session termination, inactivity limits, and storage restrictions. |

**Preferred strict-$0 order:**
1. Use **existing GitHub issues/actions** for public tasks and outbound status, at no *new* hosting cost.
2. For a genuine private always-connected chat gateway, check whether an **existing owner-controlled machine/VM** is already running and has spare capacity; *reuse that first*. If not, **Oracle Always Free A1** is the most practical candidate subject to availability and secure account setup. Limit initial bot gateways to 3, not 10 always-running model processes.
3. If already on Google Cloud, use **Cloud Run only as a request-triggered webhook** or an **e2-micro** only after calculating separate IPv4, egress, secrets and disk charges. Do not create or upgrade a paid service without explicit cost authorization.
4. When private bots exist, use **encrypted persistent volume and one owner-controlled credential store**, with user/sender allowlists and a separate identity per bot. Google Cloud Secret Manager's current monthly free allowance is **six active secret versions and 10,000 accesses shared by billing account**, if remaining after existing browser secrets. It is *not* an inexhaustible free enterprise password vault. Native provider OAuth scopes and customer consent are separate.
5. Keep Plenum's original Deep Agents Chief, n8n automations and science memory; Hermes is a **user-facing communication gateway**. Neither Telegram nor a free VM grants access to Gmail, Stripe, Google Drive, bank accounts, browser cookies or ChatGPT connector tokens.
