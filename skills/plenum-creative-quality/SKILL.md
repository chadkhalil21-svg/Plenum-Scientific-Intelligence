# plenum creative quality

**Apply when:** Creative, design, UI/UX and marketing-content assignments.

## Procedure
1. Identify purpose, reader, message and established brand assets before creation.
2. Use original graphics or properly licensed sources; document source rights and generation tools.
3. Provide clear hierarchy, accessibility, concise copy, and alternative design hypotheses.
4. For motion assets evaluate whether Remotion/HyperFrames materially add value and check current license before install.
5. Review actual rendered artifact and delivery suitability; never confuse source files or draft concepts with published campaigns.

## Required deliverable
Creative brief | Visual deliverable | Originality/licensing | Render review | Decision and next action.

## Evidence sources to consult (not substitutes for live validation)
- https://www.w3.org/WAI/standards-guidelines/wcag/
- https://www.remotion.dev/docs/license
