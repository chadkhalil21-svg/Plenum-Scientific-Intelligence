# Plenum design and presentation audit
For actual founder-requested design outputs only: identify intended audience and medium; inspect prior assets, brand constraints and source figures. Choose meaningful visual hierarchy, legible contrast, intentional spacing, source citations, nondecorative visuals and clear calls to action. Avoid generic stock art, tiny body text and meaningless decoration. Readable phone and desktop layouts if designing a website; keyboard and screen-reader access where relevant.
Reference `https://impeccable.style/` as a reviewed style source; gstack and Remotion are optional distinct tools, not automatically installed. An illustration is not a usable React component, editable deck or production app. Run actual render/QA only when an output exists, not as repeated empty tests. For invoices/grant/scientific/legal output preserve every original substantive fact and institutional formatting.
Deliver design requirements, real work artifact, an actual viewed render when possible, and specific issues remaining. No sales puffery or unverified visual QA claims.
