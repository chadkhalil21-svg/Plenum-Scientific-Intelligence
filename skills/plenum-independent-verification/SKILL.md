# plenum independent verification

**Apply when:** Verification & Advisory Council independent evidence acceptance.

## Procedure
1. Define the exact new claim and accepted evidence; retrieve independently from original authority.
2. Differentiate source-listed, software merged, workflow passed, real third-party task completed, and deployed persistent service.
3. Challenge optimism, misleading denominators, invented quotes and inferred account access.
4. When unchanged functionality already has authentic tests, reuse prior accepted evidence; test only changed or unproven capability.
5. Return PASS, PARTIAL or BLOCKED with source evidence and the single concrete missing proof.

## Required deliverable
Claim | Independent evidence | Scope | Status | Decisive remaining test or blocker.
