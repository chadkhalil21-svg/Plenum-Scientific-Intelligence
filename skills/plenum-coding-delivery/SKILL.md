# plenum coding delivery

**Apply when:** Engineering and Manufacturing coding assignments and software modernization.

## Procedure
1. Inspect original repository/issue/ledger and the current working system; detect whether feature already exists.
2. Specify a single user-visible accepted outcome and the smallest source change to obtain it. Reuse official APIs and upstream adapters.
3. Use existing Superpowers engineering practices: simple plan, tests for changed behavior, code review and recovery plan.
4. Avoid duplicating previously passed tests and never blindly replay a failed user-facing action.
5. Record actual PR, diff, relevant focused check, release status and what remains unverified.

## Required deliverable
Original gap | Minimal change | Version/license | Changed files | Focused verification | Independent deployed outcome or blocked reason.
