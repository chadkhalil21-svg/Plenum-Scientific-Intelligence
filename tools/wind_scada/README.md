# Original public wind-sensor validator (#362)

Use official [OpenOA v3.2](https://github.com/NREL/OpenOA/tree/35e8a52c4cd8f43223f8181153d4e3f083f090d2) (BSD-3-Clause), annotated tag object `d580ee6bc14d20e384dbb861278428cb840818a5`, peeled commit `35e8a52c4cd8f43223f8181153d4e3f083f090d2`. The validator imports `SCADAMetaData`, `column_validator`, `find_duplicate_times`, `find_time_gaps` and `range_flag` directly; it does not implement another QA framework or silently clean raw data. Run `python -m pip install /path/to/pinned/OpenOA` and `python tools/wind_scada/validate.py --help`.

The reference input is ENGIE La Haute Borne wind farm data, original dataset updated 9 Oct 2019, published under [Etalab Open Licence 2.0](https://www.etalab.gouv.fr/wp-content/uploads/2018/11/open-licence.pdf), as attributed by the [official upstream data license](https://github.com/NREL/OpenOA/blob/35e8a52c4cd8f43223f8181153d4e3f083f090d2/examples/data/readme.md). The pinned immutable `examples/data/la_haute_borne.zip` SHA256 is `be5ea66a3355286e491f5618250dc83e85252a8cb337748d7ba19edc50df6138`; its observed `la-haute-borne-data-2014-2015.csv` member SHA256 is `9be32aabe7e6b911f58ad3a9f292aed1e5b48cdc603b35d3feccb94f4c043cf4`. Use only that CSV, the asset ID table and official metadata. Do not use the example's artificially produced meter and inferred curtailment values as observation evidence. The raw source remains available from upstream; do not duplicate it in this repository.

The published plant metadata declares 10-minute sampling and maps power (kW), speed (m/s), relative and absolute direction (degrees), pitch (degrees) and ambient temperature (C); the source's data description additionally identifies nacelle angle `Ya_avg` (degrees). Preserve the explicit source offset, convert to UTC, check against Europe/Paris including DST, identify off-grid and repeated asset-UTC pairs, interior cadence gaps per asset, and missing/non-numeric/non-finite raw sensor values. The optional -15 to 45 C screen mirrors the upstream ENGIE example's cleaning thresholds; it is a screening heuristic, not proof that all outliers are physically impossible. Negative power can represent turbine consumption and angle conventions differ: do not silently reject these or assert calibration. Status and derived energy are not required by the original SCADA input schema.

Reports are `report.json`, `row_diagnostics.csv` (logical CSV record number, counting the header as 1), and `missing_utc_slots.csv`. Gaps are interior to each asset's observed on-grid span, not missing data outside that span. Default exit 0 means clean within the checked scope, 2 means findings or incompatible schema; `--audit` returns 0 for successful inspection even when quality findings are reported, not a declaration that the data are clean. The bounded PR job uses authentic original data and one explicitly labeled malformed-input adapter acceptance, no model or paid service.
