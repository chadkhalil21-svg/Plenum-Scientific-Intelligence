# Plenum Prometheus | Workforce Command Center

**Purpose:** single visual overview of canonical Plenum Chief and specialist roles, public GitHub Actions, scheduled workflows and founder-issued public tasks. Free browser speech dictation/briefings are built in.

**Privacy:** The site is PUBLIC, read-only, and uses only the existing public GitHub repository. It does NOT access private issues, connected email, Stripe, unpublished patents, owner credentials, confidential tasks, or registered website sessions. Profile registration is not proof of 24/7 model hosting.

**Live status:** dashboard calls unauthenticated GitHub public API with a five-minute poll interval, and reads public YAML schedule definitions. Browser vendor may send dictated speech off-device; never use public voice input for sensitive material.

**Commands:** a selected department or Chief generates a prefilled PUBLIC GitHub issue; a human must review and submit at GitHub before the original restricted workflow runs. This is NOT automated posting, payments, production changes or messaging. The existing Chief supports only a narrow, predefined domain/task boundary; other kinds should be routed directly to the appropriate known department.

**ElevenLabs:** no live credential and no API key in this static client. ElevenLabs premium voice is optional. Its official documentation requires server-generated, temporary signed URLs from a protected authenticated endpoint. A free 10,000-credit plan does not mean unlimited free voice. Current default is browser Web Speech API and device/system voice.

**Hosting:** public static file at `dashboard/index.html`; suitable for a free static host. GitHub Pages (if enabled by an administrator) or Render Static Sites can serve it. Render/Hobby bandwidth and pipeline usage may trigger charges if free allocations are exceeded.

**Video review:** user provided seven YouTube links. Relevant approaches: Agency Agents and browser-use (previously adopted), Kilo Code (optional IDE UI, not another Plenum supervisor), OnDemand agent marketplace (would duplicate orchestration), Elephant-Goldfish (fresh-review method worth applying to Verification Officer), always-on Jarvis (host + browser/email/calendar/voice, not inherently free or deployed), and general consumer AI hacks (not an operational agent platform). Primary requirement is a verifiable dashboard plus working workforce control, not additional personas.

**Source evidence:** `integrations/hermes/roster.json`, `.github/workflows/founder-chief-workforce-command.yml`, `.github/workflows/business-workforce-n8n-agent-trial.yml`, `.github/workflows/workforce-public-inbox.yml`.

**Definition of done:** Verify the deployed HTTPS URL, observe live public GitHub data (not injected fixtures), render on mobile, use browser speech or document the unavailable feature, confirm task-preparation link requires founder submission. Real private task/agent control needs separate authenticated backend and should not be conflated with this public dashboard.
