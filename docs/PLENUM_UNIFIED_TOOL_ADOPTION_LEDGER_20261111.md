**Version 1.0 — 11 November 2026** | Founder-requested, public-only inventory | Accountable: existing Plenum Chief | Independent acceptance: Verification Council

## Purpose, scope and decision rule
This is the canonical **deduplicated register of the founder's enumerated names**, merged with the existing workforce tools required to operate them. It is an **inventory and delegation plan, not proof of automatic installation, license, running process, or permission grant**. Product identity for vague names is explicitly unresolved rather than fabricated. Titles, timestamps, generic patterns, training materials and game environments are not counted as agent employees. Some names were repeated verbatim in the source list, and some appear in multiple contexts; each named entry appears **once** in the category tables below. This file supplements the [workforce master ledger](PLENUM_WORKFORCE_MASTER_LEDGER.md), the [prior adoption ledger](PLENUM_FOUNDER_PLATFORM_ADOPTION_LEDGER.md), the [skill and tool ledger](PLENUM_AGENT_SKILLS_AND_TOOL_LEDGER.md), and the [original workforce inbox](WORKFORCE_INBOX.md). This is public-only; no private company records should be copied here.

**Editorial method:** selected per the private Plenum document-production standard consulted 2026-11-11: intended audience founder/operations, concise decision-first register, original-source vs proposal distinctions, explicit next ownership and acceptance. No fabricated product capacities or approved budgets.

**Adoption states:** `EXISTING*` means source/method/provider known from the original repository, **not** general live access; `CONNECTED_CHAT_ONLY` means the ChatGPT-side app is not thereby connected to GitHub Actions; `PRIORITY/PILOT` means first worthwhile zero-new-charge task, not installed; `OPTIONAL` means evaluate only with a case; `DEFER*` means no present cost justification; `IDENTIFY` means verify exact upstream identity; `BLOCKED_EXTERNAL` requires actual provider availability/owner grant. No provider account, license or cost is assumed.

**Free-first policy:** Favor reusable local/open-source code and existing GitHub tools. Any hosted provider requires a verified free allocation, legal/license review, a scoped permission grant if applicable, and a fail-closed spend limit of $0 incremental charges. Do not integrate redundant supervisors, do not install every tool, and do not use public CI as commercial always-on inference. Count independently accepted real outputs, not personas, workflow definitions, or platform names.

## Original-source verification and cost notes
- **Google AQuA:** precise Google project label is **not corroborated**; prefer the official [Google ADK agent evaluation documentation](https://google.github.io/adk-docs/evaluate/) and established failure-classification guidance rather than assuming this tool exists.
- **Freebuff:** [vendor](https://freebuff.com/) and [repository](https://github.com/CodebuffAI/freebuff) describe ad-funded coding, with daily model/hour limitations, privacy terms and optional paid upgrades; **not** truly unlimited free compute for our workforce.
- **Airia:** [official pricing listing](https://legal.airia.com/pricing/) lists paid Professional from $25/month, while other current public listings mention trial/free allowances; **do not assume ongoing free no-code agent capacity**.
- **SideShift:** [vendor](https://sideshift.app/) describes creator campaigns and paid software; not a free-first priority.
- **Graft:** [documentation](https://docs.getgraft.ai/graft/get-started/what-is-graft) describes MCP tool generation alongside an existing agent; never permit unsupervised live credential/data mutation.
- **Monologue:** several distinct voice products share the name: [Every's Monologue](https://www.monologue.to/), [monologue.run](https://www.monologue.run/), and [Monologue voice journal](https://monologueapp.co/); exact intended one requires identity match.
- **Remotion:** [official licensing](https://www.remotion.dev/docs/license/pricing) depends on organizational situation and use; rendering can consume compute even if source is available.
- **Cloudflare Workers:** [official free limits](https://developers.cloudflare.com/workers/platform/limits/) do not grant a private resident unlimited AI server.
- **GitHub Actions:** [official hosted-runner limits](https://docs.github.com/en/actions/reference/limits) and platform terms must govern legitimate bounded development workloads.
- **Prior original infrastructure:** [workforce evidence](PLENUM_WORKFORCE_MASTER_LEDGER.md) and [inbox trigger](WORKFORCE_INBOX.md). Five logical workforces do not mean five resident model systems.
