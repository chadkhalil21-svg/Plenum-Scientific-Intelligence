# Candidate open-source projects

We link to upstream software instead of bulk-copying it. Each adapter needs a license review, pinned version and validation.

- Local models: https://github.com/ollama/ollama
- OpenAI Agents SDK (optional, hosted costs): https://github.com/openai/openai-agents-python
- Agent graphs: https://github.com/langchain-ai/langgraph
- AI Scientist reference (custom licensing): https://github.com/SakanaAI/AI-Scientist-v2
- Scientific-agent catalog: https://github.com/K-Dense-AI/scientific-agent-skills
- Biomedical workflows: https://github.com/snap-stanford/Biomni
- Theorem prover: https://github.com/leanprover/lean4
- NASA orbital simulation: https://github.com/nasa/GMAT
- Optimization: https://github.com/OpenMDAO/OpenMDAO
- Aerodynamics: https://github.com/su2code/SU2
- Molecular dynamics: https://github.com/openmm/openmm
- Quantum chemistry: https://github.com/pyscf/pyscf
- Materials: https://github.com/materialsproject/pymatgen
- Battery simulation: https://github.com/pybamm-team/PyBaMM
- Astronomy: https://github.com/astropy/astropy

Literature: https://openalex.org/ ; https://arxiv.org/ ; https://www.ebi.ac.uk/europepmc/ ; https://www.osti.gov/

Only a basic OpenAlex metadata adapter is implemented at present. Listing a project does not install or validate it.
