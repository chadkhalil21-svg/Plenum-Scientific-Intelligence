# Plenum Reasoning-Model Comparison and Scientific Hypothesis Candidates

Status: **candidate evaluation only, not AGI, a discovered law, or self-improvement**.

## From tools to independently evaluated reasoning

The existing Qwen3-0.6B numerical solver pilot used real model inference,
but selected RK45 (806 evaluations) when DOP853 (254) was better on a heldout
test. This upgrade compares Qwen3-0.6B with Qwen3-1.7B on the exact same
predeclared public scientific software examples.

Separate GitHub CPU jobs perform real, revision-pinned model inference:
- Materials and chemistry are the two development fixtures.
- Electronics and mechanics are the two sealed holdout domains.
- Every model selects numerical methods based on development-only metrics.
- Both models produce an original structured experimental-hypothesis draft.
- The independent evaluator recomputes development results before revealing
  holdout values. It preserves incorrect model choices and compares the
  strongest known benchmark method.
- The research-memory branch saves public results of completed main-branch runs.

The model draft must include a testable hypothesis, an experiment, a falsifier
and an alternative explanation. It is marked unverified. The text is never
executed as computer code, and no experiment or invention is claimed because
a model produced a paragraph.

## Operate from an iPad

GitHub > Actions > Compare Reasoning Models and Draft Falsifiable Hypotheses >
Run workflow. A monthly public generic run is also scheduled. Scheduled GitHub
jobs may be skipped or delayed.

The reports include immutable model revision hashes, source provenance,
scientific tool checks, failures, measured decisions and explicit nonpromotion.
All computations use public CPU models and existing test software; no
paid inference account or persistent GPU service is activated.

## Strict limits

This is only two known-equation holdout cases per model. It does not prove
superior general intelligence, autonomous scientific invention or improved
model weights. Public tasks may overlap model pretraining. CPU memory and
runtime demands can cause failed model jobs; never claim a score when that
happens. Green GitHub checks do not themselves establish intelligence.

Before any real model promotion, compare on larger genuinely unseen
interdisciplinary evaluations, scientific literature grounding, code
generation and validation, reasoning, privacy, robustness, cost and latency.
Use an independent evaluator, versioned rollback and human authorization.

## Future private autonomous intelligence

GitHub Actions is a bounded execution and verification tool, not an
always-running private research computer. Use existing LangGraph and SQLite
checkpoints for experiments. Persistent private Plenum research requires
owner-approved authenticated hosting, encryption, backups, queues, strict
permissions, budget ceilings and a tested inference service. Do not put
unpublished patents, company research, or credentials in this public repo.

External generated programs remain proposals for review, never automatically
deployed or executed with unrestricted shell privileges. Retain negative
outcomes as valuable evidence and measure gains before claiming progress.
